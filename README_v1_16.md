## 1. Что изменилось

Убрана панель **Presets** из панели управления.

Было:

```
Presets
[↺ Reset] [Typical turn] [PP outside hull] [No yaw] [Turn to starboard]
```

Стало:

* блок «Presets» удалён целиком;
* кнопка **↺ Reset** (полный возврат к исходному состоянию) перенесена в панель
  расписания, рядом с «Reset schedule», и переименована в **↺ Reset all**;
* удалён мёртвый код: объект `presets` и обработчик `[data-preset]`;
* номер версии в заголовке, подзаголовке и в данных состояния — 1.16.

## 2. Что теряется при удалении панели

| Кнопка | Что делала | Смысловая нагрузка | Потеря |
|---|---|---|---|
| Typical turn | ставит расписание 1.5 / −0.8 / 5 kn | ровно то, с чего программа стартует, и ровно то, что делает ↺ Reset | ничего — дубль |
| PP outside hull | 5.0 / 4.0 / 5 kn, оба борта вперёд | демонстрация случая «точка поворота вне корпуса» | мгновенный доступ к одному из особых случаев; воспроизводится тремя числами |
| No yaw | 1.5 / 1.5 / 5 kn, рыскание = 0 | демонстрация вырожденного случая «PP не определена» | то же — редкий, но поучительный случай |
| Turn to starboard | −1.2 / 0.6 / 8 kn, тяга на корме | быстрый пример разворота на корме | то же — воспроизводится ползунками |
| ↺ Reset | корпус, горизонт, масштаб и расписание → значения по умолчанию | единственная кнопка, возвращающая всё сразу | **ничего — кнопка сохранена** как «↺ Reset all» |

Итого: удалены четыре демонстрационных сценария, которые в любой момент набираются
вручную; ни одно вычисление, ни один график, ни одна функция программы не пострадали.
